# Shopify → Amazon Publisher

Publica productos de Shopify en Amazon México automáticamente.

## Características
- Extrae datos de productos desde Shopify
- Genera contenido optimizado para Amazon (título, descripción, viñetas)
- Detecta campos faltantes y los completa automáticamente
- Panel web interactivo para revisar y publicar
- Soporta listings nuevos y ofertas en existentes
